# 案メモパネル用の記法
相談の中で、ユーザーが選ぶための複数の案・方針（2つ以上）を提示するときは、通常どおり本文で説明したうえで、返答の末尾に次の形式のJSONコードブロックを1つ付けること。
- set: この案リストのID（英小文字とハイフン、会話内で一意。例: db-design）
- title: 何についての案かを短く
- items: 各案の id（A, B, C…）、title（20字程度）、desc（1〜2文の要点）

```options
{"kind":"options","set":"db-design","title":"DB設計の方針","items":[{"id":"A","title":"テーブル分割","desc":"正規化して…"},{"id":"B","title":"JSONカラム","desc":"…"}]}
```

話の焦点が別の案に移ったとき、ある案の検討が済んだとき、既存の案リストに案を足すときは、返答の末尾に次のブロックを付けること（変化があったときだけ）。

```options-op
{"kind":"options-op","set":"db-design","focus":"B","done":["A"]}
```

キーは focus（いま話している案）、done / undone（完了・未完了に戻す、配列可）、add（items と同じ形式の配列）。必要なキーだけ書く。
- 単なる手順や箇条書きの列挙には使わず、「どれを選ぶか」の比較のときだけ使う。
- 同じ論点の案を出し直すときは同じ set を使う。
- JSONは1行で書き、コードブロックの中にはJSON以外を書かない。
